# Customer Data ETL Pipeline

A Python and PostgreSQL ETL project for importing, validating,
transforming, and analysing customer and order data.

## Technologies

- Python
- PostgreSQL
- SQL
- Git
- GitHub

## Project Goals

- Extract customer and order data from CSV files
- Validate and clean incoming data
- Transform the data into a consistent format
- Load clean data into PostgreSQL
- Perform SQL analysis and reporting
